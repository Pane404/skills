# Skills

这里收录可复用的 Agent Skill 成品。

| Skill | 标识 | 用途 |
| --- | --- | --- |
| [前端交互选型与评审](frontend-interaction-spec/) | `frontend-interaction-spec` | 根据业务场景和数据特征选择前端交互，核对状态反馈、浮层、表单、键盘操作与读屏行为。 |

## 使用

获取所需 Skill 的完整目录，保留其中的文件结构。按所用 Agent 宿主的方式启用，或在任务里让 Agent 读取该目录的 `SKILL.md`。入口文件也记录了当前版本。

例如，可以使用 [前端交互选型与评审](frontend-interaction-spec/SKILL.md) 询问「用户需要跨页选中筛选结果并批量通知，遇到发送超时该怎么处理？」
