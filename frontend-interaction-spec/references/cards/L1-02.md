### L1-02 图标按钮（Icon Button）

- 判断句：空间极窄且图标含义跨文化公认的次要动作用 IconButton（必填 `aria-label` 与 hover 等价路径按 HR-09 / HR-07）；动作是产品自造或主/破坏性操作改用 L1-01 带文字 Button，点完去别的网址改用 链接 Link，要记住开/关改用 L1-07 Toggle。
- 不用：自造动作/图标含义要猜 → L1-01 带文字 Button（替代）；短文字其实放得下（表单底/空状态/CTA）→ 带文字 Button；主操作/破坏性主操作 → L1-01 Button / L1-05 FAB（替代）；只是状态/装饰图形 → 非交互 `<span>`/`<img>` + `aria-hidden`。
