### L1-03 按钮组（Button Group）

- 判断句：2–5 个同类、同级、相关的一次性动作要绑成一个视觉/语义单元用 Button Group（`role="group"` 按 HR-09，命中区间距按 HR-01）；要持久保持一个选中态改用 L1-08 Segmented / L2-16 Radio，「一个默认动作+变体」改用 拆分按钮 Split Button，一整条塞多组东西改用 工具栏 Toolbar。
- 不用：需单选且显示当前选中 → L1-08 Segmented / L2-16 Radio（替代）；动作权重差异大 → 独立 primary+secondary Button；破坏性与常规动作紧贴 → 拆开 + danger Button + 确认；>5 个或窄屏放不下 → 工具栏 Toolbar 的 More 溢出菜单（替代）。
