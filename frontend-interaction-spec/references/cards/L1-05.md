### L1-05 浮动动作按钮（Floating Action Button / FAB）

- 判断句：一屏唯一、建设性、需滚动时始终可达的主操作用 FAB（一屏一个与 `aria-haspopup` 如实按 HR-09，命中区按 HR-01）；有两个同等重要动作或桌面宽屏改用 L1-01/L1-03 Button，图标说不清改用 Extended FAB，要展开 2–6 个相关动作改用 FAB menu。
- 不用：破坏性/次要/溢出/告警动作 → 行内 Button 或 工具栏 Toolbar（替代）；导航 → L5-04 底部导航等；主操作已在顶栏/内容区 → 不重复放 FAB；卡片/列表项各自一个「+」→ L1-02 IconButton（替代）。
