### L10-01 焦点态与焦点环（Focus State / Focus Indicator）

- 判断句：先消歧：`:focus`（有无焦点）≠`:focus-visible`（要不要给键盘看）≠`:focus-within`（容器整行亮），详见 [index/glossary.md](../index/glossary.md)；焦点环是键盘用户的「光标」，不是装饰。
- 用：图标按钮逐行 Tab 时环是「按到哪行编辑」的唯一线索；深色 Hero / 页脚链接，因为单色环会消失，须按主题定义 `--color-focus` 或双色环。
- 不用：裸 `outline:none` / `outline:0` 不给替代 → 改 `:focus:not(:focus-visible){outline:none}` + `:focus-visible` 成对规则；用 `1px` 淡边框 / 背景微变当焦点态 → 改实线环 + `outline-offset`（环宽数值见 HR-03）。
- 必检：主规则 `:focus-visible`、老引擎用 `@supports selector(:focus-visible)` 留 `:focus` 兜底（B）；深浅双主题各一份焦点色、`forced-colors:active` 用 `Highlight` / 透明 outline 兜底（A/B）。
  `overflow:hidden` 边缘用 `outline-offset`/padding 留绘制空间、不用 `border-width` 变化免 layout shift（B）；sticky 头遮挡按 HR-03，本条特有边界是配 `scroll-padding-top` / `scroll-margin`（A）；reduce 只停动画不隐藏环（HR-10）。
  共享：环宽 / 对比度按 HR-03 / HR-02、移入与归还落点可见按 HR-04，数值不在此重复。
- 契约：服务 C1（焦点移入的首个落点须带可见环）；本条不决定是否模态，模态性由 `showModal()` 定、不由遮罩样式定（HR-06）｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
