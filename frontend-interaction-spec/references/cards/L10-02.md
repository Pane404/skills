### L10-02 键盘导航（Keyboard Navigation）

- 判断句：先消歧：全局 Tab 顺序（组件间、DOM 源序）≠ roving tabindex（组件内、方向键）≠ 焦点困住（仅模态），详见 [index/glossary.md](../index/glossary.md)；判据「整页能否放下鼠标只用键盘走通」。
- 用：结算页 CSS 把「支付」视觉放底部而 HTML 排第一 → 改 HTML 源顺序而非正整数 tabindex；标签页 / 工具栏 / 菜单用 roving tabindex 让整组只占一个 Tab stop。
- 不用：`tabindex="1"` 等正整数修顺序、`div`+`onclick` 当按钮 → 改 DOM 源顺序 / 原生 `<button>`；CSS `order`/绝对定位重排不动 DOM、隐藏内容留可聚焦子元素 → 重排 HTML / 用 `inert` 或真隐藏属性。
- 必检：`tabindex` 只用 `0` 与 `-1`（MDN，A）、复合组件 roving tabindex 只占 1 个 Tab stop（APG，A）；首个 Tab stop 是可见 skip link（2.4.1，A）、SPA 路由切换把焦点移到 `<main>` / `<h1 tabindex="-1">`（A）、异步内容插在触发元素之后维持顺序（SCR26，B）。
  隐藏 / 闭合内容（`display:none`/`hidden`/`inert`）不接收焦点（A）；禁用项用 `aria-disabled="true"` 保留可聚焦（B）；标准键位 Tab/Shift+Tab/Enter/Space/方向键/Home/End/Esc（A）。
  共享：原生元素优先 HR-09、焦点移入 / 归还 HR-04、Esc 出口 HR-05、焦点环 HR-03、触控 HR-01；「除非模态」按 HR-06 由 `showModal()` 定。
- 契约：全局通路基础，对应 C1（焦点移入）与 C2（Tab 循环）的底层；非模态不让 JS 接管 Tab 禁出，模态例外须给 Esc 出口（HR-05 / HR-06）｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
