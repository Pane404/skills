### L10-03 焦点困住（Focus Trap / Focus Containment）

- 判断句：先消歧：focus trap（模态打开期间的有意设计）≠ keyboard trap（WCAG 2.1.2 禁止、能进不能出），详见 [index/glossary.md](../index/glossary.md)；分界只有一条——是否给 Esc / 关闭按钮出口。
- 用：删除账户确认、模态表单、全屏向导，因为 Tab 逃到被遮背景会误触发看不见的破坏性按钮；嵌套浮层 / Lightbox 用栈管理，内层关闭只回外层。
- 不用：非模态侧栏 / 属性检查器 / 聊天窗 → 不困住，送焦点进去 + 关闭归还但不拦截通往页面的 Tab；Tooltip / Peek 只读浮层用 `aria-describedby` 不抢焦点、`aria-modal="true"` 冒充 → 补真实 trap + 背景 `inert`。
- 必检：打开移入首个可聚焦元素（或容器 `tabindex="-1"`）、Tab 到末尾 wrap 首 / Shift+Tab 反向 wrap（C2 判定，A）；可聚焦集合须过滤 `disabled`/`tabindex="-1"`/`hidden`/`inert` 祖先且异步增删后重新查询（D）；嵌套用栈、内层关闭归还外层浮层触发项（D）。
  确认类初始焦点给「取消」最不破坏动作（B）；触发元素卸载回退到最近存活容器 / `<main tabindex="-1">`，绝不 `document.body.focus()`（HR-04）。共享：`showModal()` 原生 trap 首选按 HR-06、Esc 出口 HR-05、焦点环可见 HR-03、关闭归还 HR-04。
- 契约：即 C2；仅模态启用，原生与自定义模态的判据按 HR-06，非模态面板禁用困住｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
