### L10-04 焦点归还（Focus Return / Focus Restoration）

- 判断句：先消歧：归还（关闭后回触发者）≠ 困住（打开期间不逃出）≠ autofocus（挂载抢焦点、方向相反），详见 [index/glossary.md](../index/glossary.md)；缺困住焦点乱跳、缺归还焦点掉 `<body>`，是两类独立失败。
- 用：列表页编辑按 Esc 取消要回到「那一行的编辑按钮」、嵌套浮层用栈逐层归还；删除确认 / 虚拟列表触发行被卸载 → 回退到下一行 / 列表容器。
- 不用：关闭时 `document.body.focus()` / 让浏览器定落点 → 显式回退链「触发者 → 最近存活列表行 / 父容器 → `<main tabindex="-1">`」。
  不校验就 `trigger.focus()` 写进卸载同帧、`setTimeout(300)` 猜动画 → `isConnected` 校验 + `close`/`transitionend`/rAF 延后、监听事件而非猜时长。
- 必检：Capture-Validate-Restore 三阶段（打开前存 `document.activeElement`；校验 `isConnected`/非 `disabled`/无 `inert` 祖先/`offsetParent!==null`；`focus({preventScroll:true})` 延后到 `close`/rAF）（APG，A / 实现 D）。
  五条关闭路径（Esc、X、遮罩、`method="dialog"` 提交、程序关闭）收敛到唯一 close 函数（D）。
  背景仍 `inert` 就 `.focus()` 会静默失败 → 先 `page.inert=false` 再聚焦（HR-06 / HR-04）；走回退目标须用 polite live region 说明焦点去向（HR-10）；提交成功跳新路由不归还、交给新页 `<h1>` 并播报（D）。
  共享：归还触发者 / 不掉回 `<body>` 按 HR-04、落点焦点环可见且不被遮挡按 HR-03（本条特有边界配 `scroll-margin`）。
- 契约：即 C4（关闭后 `.focus()` 归还触发者，触发者消失落最近合理元素）；所有关闭路径共用归还｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
