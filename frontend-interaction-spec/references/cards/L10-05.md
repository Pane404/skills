### L10-05 Esc 关闭语义（Escape / Close Request Dismissal）

- 判断句：先消歧：Esc 关闭（键盘请求、只关栈顶一层）≠ light dismiss（点外部 + Esc 的合称）≠ 关闭按钮文案，详见 [index/glossary.md](../index/glossary.md)；Esc 是焦点困住的合法出口、键盘用户「唯一可点的外部」。
- 用：模态里开的下拉 / 日期选择器第一次 Esc 只关菜单、父对话框保持，`popover="auto"` 浮在 dialog 上时浏览器先关顶层 auto；命令面板等无外部可点的场景 Esc 是唯一等价出口（2.1.2）。
- 不用：每个浮层各挂 `document` keydown 广播式全关、`keyup` 绑定 → 单一全局 `keydown` 监听 + 层栈只取 `stack[last]`；Esc 连带关父层 → 顶层 `preventDefault()`+`stopPropagation()` 后 pop 一层、不冒泡。
- 必检：单一 `keydown` 监听 + 层栈（只取栈顶、`preventDefault()`+`stopPropagation()`、一次 pop 一层，D）；`<dialog>` 的 `cancel`→`close` 事件链、`popover="auto"` 由浏览器先关顶层（HTML/MDN，A）。
  `closedby` 可选 `any` / `closerequest` / `none`。缺省 Auto 按打开方式判定：`showModal()` 接受关闭请求，`show()` 默认不接受（HTML，A）。
  含未保存输入不静默丢弃：保护放 `cancel` handler 弹「保存 / 丢弃 / 继续编辑」，不能只靠 `closedby="none"`（Safari 未支持会忽略，B/D）；阻止关闭给可见原因并 `aria-describedby` 关联焦点控件（B）、每个可 Esc 关闭浮层配可见关闭按钮（A）。
  提交挂起时同样不能只禁用 Esc / 关闭：给可见「后台继续 / 查看状态 / 取消」出口，Esc 触发 guarded closing；结果未知时提供查询，不重复提交（A/D）。
  共享：Esc 只关最顶层按 HR-05、关闭后归还触发者按 HR-04、模态性按 HR-06。
- 契约：即 C3（Esc 只消费最顶层、嵌套不得连带关父层）；dirty form 走 guarded closing 而非禁用 Esc｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
