### L10-06 轻点外部关闭（Light Dismiss / Click Outside to Close）

- 判断句：先消歧：light dismiss（点外部 + Esc 的关闭策略，判据是「后果」不是尺寸）≠ Esc 关闭（键盘半边）≠ `popover="manual"`（不可轻关），详见 [index/glossary.md](../index/glossary.md)；「点出去会不会让用户丢东西」定策略。
- 用：工具栏筛选 popover / 菜单、日期·颜色 picker、纯信息 Lightbox / 成功提示，因为关掉零损失；多个教学提示用 `popover="auto"` 互斥只显一个、Toast 用 `popover="manual"` 不因点一下全消失。
- 不用：含未保存输入 / 破坏性确认 / 登录结算 → 禁用点遮罩关闭（`closedby="none"`/`closerequest`）或先弹丢弃确认、必须逼决策用 `<dialog>.showModal()`。
  `popover="manual"` 无关闭控件 → 补 `popovertarget` hide / `hidePopover()` / 超时清理，`click`+`event.target` 判外部 → `pointerdown`+`getBoundingClientRect()` 坐标且按下抬起都在外部。
- 必检：`popover="auto"`（点外部 / Esc / 打开另一 auto 关前一个，嵌套 auto 例外共存）/`manual`（不轻关、可并存、须显式关闭）/`hint`（A，WHATWG/MDN）；`closedby`=`any`/`closerequest`(modal 默认，点遮罩不关)/`none`（A）。
  `popovertarget` 隐式 `aria-expanded`/`aria-details`、Esc 回 invoker，不重复加 `role="dialog"`/`aria-modal`（HR-09 / A）。
  点遮罩关闭属台账保留分歧、须列各方不调和：Polaris 一律不(B) / Radix 默认可(D) / iOS·Android 各异，按「是否含未保存数据」分型（D）；轻关闭 `pointerdown`、点外关闭按 HR-05。
  关闭路径全集（X / Esc / 点外部 / Back / 滑动 / 程序 / 超时）收敛同一 `requestClose()` 统一归还（HR-04 / D）；top layer ≠ 模态、不困焦点不锁背景（HR-06 / A）。
- 契约：非模态；对应 C3 的 Esc 半边与 C4 关闭后归还触发者，C1 弱化适用 / C2·C5·C6 不适用；「必须决策」用 `showModal()` 而非给 popover 加遮罩（HR-06）｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
