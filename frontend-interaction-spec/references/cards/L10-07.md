### L10-07 滚动锁定（Scroll Lock / Body Scroll Lock）

- 判断句：先消歧：scroll lock（管滚动）≠ `inert`（管可达性，不是滚动锁）≠ `overscroll-behavior:contain`（管滚动链），详见 [index/glossary.md](../index/glossary.md)；锁「真正的滚动根」并消除撤滚动条的横向跳版。
- 用：长列表滚到中部打开编辑对话框 → 锁背景并保存滚动位置，含长表单模态 → 浮层给 `max-height`+`overflow:auto` 独立滚动区；Windows 经典滚动条环境，因为 `overflow:hidden` 撤掉 15–17px 条会致 CLS。
- 不用：只写 `body{overflow:hidden}` → 加 `html{scrollbar-gutter:stable}` 并确认锁真正滚动根（app shell 自管滚动时锁那个 div）；用 `inert`/`aria-modal`/高 `z-index` 冒充 → 滚动另用 `overflow`+`overscroll-behavior` 二者并用。
  `wheel`/`touchmove` 全局 `preventDefault()` → 声明式滚动容器 + contain。
- 必检：`scrollbar-gutter:stable`（含 `both-edges`；全屏 fixed 遮罩盖不住 gutter 细缝时仍用 `padding-right` 补偿，A/B）；锁真正的滚动根（`html` / 自管 shell div 非 `body`，A）。
  浮层 `max-block-size:min(80dvh,48rem)`+`overflow:auto`+`overscroll-behavior:contain`（A/B）；嵌套用引用计数、栈空才解锁（D）；`position:fixed` 回退须成对保存还原 `scrollY`（B）；iOS `touchmove`+`{passive:false}` 且放行双指缩放与浮层内滚动（D）。
  关闭例程可逆：清类 / `--scrollbar-gap` / padding / 监听 / `inert` / 滚动位置并走归还（D）；`showModal()` 让背景 inert 但不保证阻止滚动（触屏尤甚）、需另加锁（HR-06，A）。
  reduce 下 `scroll-behavior:auto`（HR-10）；`aria-modal` 只通告按 HR-06、`focus({preventScroll:true})` 按 HR-04。
- 契约：即 C6（锁滚动并补偿宽度、避免横向跳版）；与 C5 的 `inert` 是两个独立职责、必须并用｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
