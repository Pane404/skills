### L10-08 背景 inert（Inert Background / Background Inertness）

- 判断句：先消歧：`inert`（整棵子树不可聚焦 / 点 / 读）≠ `aria-hidden`（只对读屏藏、仍能点）≠ `aria-modal`（只通告）≠ top layer（渲染层），详见 [index/glossary.md](../index/glossary.md)；让「看得见被挡」等于「真的碰不到」。
- 用：自定义 `div[role="dialog"]` 模态（遮罩只挡视线，Tab / 读屏仍到背景）、删除确认背景有「提交 / 保存」按钮 → `page.inert=true` 一次封死三条通路；嵌套浮层打开子层时显式把父浮层 `inert`。
- 不用：`aria-modal="true"` 冒充、给含可聚焦后代的元素或祖先加 `aria-hidden="true"` → 补真实 `inert` + 焦点困住（浏览器会拒绝 `Blocked aria-hidden`）。
  把 dialog 放进被 `inert`/`aria-hidden` 祖先、关闭忘移除 → 浮层放被封容器之外（`#page` 与 `dialog` sibling）、唯一 close 例程先 `page.inert=false` 再归还。
- 必检：`inert` 是布尔属性、递归继承且不可从内部撤销（`element.inert=true` / `setAttribute('inert','')`，A）；`showModal()` 自动背景 inert 首选（HR-06 / A），自定义路径 `page.inert=true` 且浮层与 `#page` 为兄弟、非被封容器后代（A/B）。
  嵌套须显式 `parentModal.inert=true`（top layer dialog 逃出祖先 inertness，D）。
  归还前必须先移除 `inert`（inert 子树不能接收焦点，HR-04 / A）；`inert` 不自动加 `aria-hidden`、不自带变暗须 `::backdrop`/scrim 明示（A/B）；范围收紧到单个容器、不给整 `<body>`、不替代 `hidden` / 表单校验（HR-09 / B）；关闭生命周期与滚动锁 / 困住 / 归还统一清理（HR-06 / D）。
- 契约：即 C5（背景加 `inert`、移出 tab 序与无障碍树，不逐个盖 `aria-hidden`）；`inert` 是 C2 的配合手段、不管滚动也不负责归还，原生与自定义模态的判据按 HR-06｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
