### L10-09 ARIA live region（ARIA 实时区域 / 状态消息播报）

- 判断句：适用状态消息在焦点不移入时提供可访问语义。常规用 polite，紧急且需立即处理时用 assertive（HR-10，A）。详见 [消歧表](../index/glossary.md)。
- 用：焦点留在筛选框时提示结果数量，或在保存后传达结果。草稿面临即时丢失且需马上处理时，可用 `role="alert"`（HR-10，A）。
- 不用：把容器连文本一起 append → 初始就渲染空容器、之后只改 `textContent`；表单校验只丢一句、整页结果塞进区域、每条普通成功用 assertive → 焦点移到错误摘要/字段 + `aria-invalid`/`aria-describedby`、只播「18 条结果」简短状态行、改 `role="status"`/`polite`。
- 必检：live region 可先挂载空区域，再更新消息文本。核对同一个状态更新只发出所需播报（HR-10，A）。
  `role="status"`≡`polite`+`atomic=true`、`role="alert"`≡`assertive`+`atomic=true`、不给 alert 叠 `aria-live="assertive"`（WAI-ARIA 1.2，A）；`aria-relevant` 默认 `additions text`（removals 少用）。
  高频 >1 次/秒 用 debounce / `aria-busy`（A/B）。
  `<output>` 是唯一隐式 `role="status"` 元素，但老组合（IE11 JAWS/NVDA、TalkBack+Firefox）不播报须显式补 `role="status"`、不擅自当全平台保证（A/B，取舍）；视觉隐藏用 `sr-only` 而非 `display:none`/`visibility:hidden`/`inert`（A）。
  限时操作按 HR-08。ARIA 状态按 HR-09。模态期间的相关消息放在活动的可访问区域（HR-06 / HR-10）；Toast / live region 不进交互栈，也不随背景 inert 一起被移出无障碍树。
- 契约：非模态，C1–C6 不适用。模态内相关播报随活动浮层可达，背景按 C5 保持受限｜详见 [浮层契约](../contracts/overlay-contract.md)。
