### L10-10 减少动效（Reduced Motion / prefers-reduced-motion）

- 判断句：reduce 是「替换动效类型」而非「缩短时长」——把位移/缩放/视差换成 opacity 淡入或瞬时切换，别核弹式 `animation:none` 删光、也别把 300ms→80ms 当降级。
- 用：模态/底部抽屉的 scale-in 与滑入、落地页视差 Hero，因 reduce 下换瞬时或 40ms opacity 翻转，直接 `animation:none` 会让面板瞬移看不出是新层；骨架屏脉冲与无限旋转 Loader，因冻结会误读为「已完成」，应换静态「加载中…」文字或确定进度。
- 不用：只压缩时长或全局 `* { animation:none !important }` → 改为替换而非移除（保留状态变化信息）、瞬时用 `0.01ms` 而非 `0s`（后者令 `animationend`/`transitionend` 永不触发）；只写 CSS 媒体查询忽略 JS 动效库 → 同时读 `matchMedia` 并监听 `change`。
- 必检：`no-preference`/`reduce` 二值、页面加载即读并监听实时变化（B）；JS 动效库、平滑滚动、`scrollIntoView({behavior:'smooth'})`、scroll-jacking、自动播放视频须读 `matchMedia` + `change`。
  显式 JS 滚动在调用端按 reduced motion 选择 `behavior:'auto'`，CSS `scroll-behavior` 不能覆盖显式参数（B/D）。
  瞬时化用 `0.01ms`、视频用静态 poster、GIF/marquee/confetti 一并降级（B/D）；>5s 运动内容保留常驻可见暂停/停止控件、每秒闪烁 ≤3 次（WCAG 2.2.2/2.3.1，A）；触屏暂停控件不藏 hover 按 HR-07。
  reduce 下焦点环、live region 播报、焦点困住、焦点归还一律保留（HR-03 / HR-04 / HR-10），只改视觉动效；以 reduce 为基线渐进增强（B）。
