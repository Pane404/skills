### L10-13 悬停陷阱（Hover Trap / Content on Hover or Focus）

- 判断句：凡只在 `:hover` 出现的内容，必须同时可 `:focus-visible` 触发、可 Esc 关闭、可悬停、持久可见；能直接写在页面上的就别藏，必须藏的用点击/聚焦展开，只有纯装饰短提示才允许 hover 触发。
- 用：图标按钮 hover 显示纯文字说明 → Tooltip，focus 同样触发 + `role="tooltip"` + `aria-describedby`；表格客户名 Peek 预览余额、HoverCard 含链接属结构化预览 → 走 L4-08 / L4-09 并给点击 / 聚焦等价入口，不塞进 Tooltip；导航 hover 巨型子菜单仍须 Esc 可关、指针可移入。
- 不用：关键信息/唯一操作藏 hover 后、只写 `:hover` 无 focus 路径 → 优先文案直接上屏，确需收起用 `<details>`/accordion/Popover API 的 click 触发；用 HTML `title` 承载可访问说明、或 hover 内容 2s 自动淡出 → 改自定义 tooltip + 常显，改 persistent 不设定时消失。
- 必检：1.4.13 三条件全满足——Dismissible（Esc 且不移动指针 / 焦点）、Hoverable（内容重叠 / 紧邻触发元素、显示态允许 `pointer-events`）、Persistent（不自动消失）。
  整体例外仅 UA 控制且作者未修改的内容（如原生 `title`）；错误信息或内容遮挡 / 替换其他内容时，Dismissible 的 Esc 例外不适用，仍须可关闭（A）。
  hover 延迟按 HR-07（台账 #8，禁 0ms、具体随库）、hover-only 给点击/键盘/触屏等价路径（触屏改 tap toggle/内联、不依赖双点击，B）；Esc 只关栈顶一层按 HR-05、关闭后焦点回触发者按 HR-04（A/B）。
  SC 2.4.11 特有边界——浮层不遮挡当前焦点/触发元素按 HR-03；`role="tooltip"`+`aria-describedby`、图标按钮可访问名按 HR-09、浮层文本对比度按 HR-02；被 `overflow:hidden` 裁切改用 top layer/Popover API/CSS Anchor（B/D）。
- 契约：非模态 hover/focus 增强；C3 适用（Esc 只关栈顶一层、不移动焦点）/C4 适用（关闭后焦点回触发者），C1/C2/C5/C6 不适用｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)
