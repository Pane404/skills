### L10-16 国际化与 RTL（Internationalization / RTL & Bidirectional Layout）

- 判断句：用 `dir`+`lang`+CSS 逻辑属性让同一套 UI 服务 LTR/RTL，镜像的是布局与方向性图标而非一切；「方向」用逻辑属性与 `dir`、「长度」用弹性容器与膨胀预算、「空间」用窗口尺寸类（见 L10-17），i18n 是结构侧、l10n 是译文内容侧。
- 用：上线阿拉伯语/希伯来语版本，因约 1/5 人口 RTL，物理方向属性会让导航/图标/抽屉全错位，须 `<html dir>` 按 locale 设一次 + 逻辑属性单一 stylesheet；从英文扩展到德/芬语后台表单与结算页价格日期，因「Sign In→Anmelden」长 40% 会撑破固定宽度按钮、`$1,234.50`/`MM/DD/YYYY` 是美式硬编码。
- 不用：用 `margin-left/right`/`left`/`text-align:left` 物理属性、或组件树到处 `isRTL ?` 分支 → 全改逻辑属性（`margin-inline-start` 等）、根上设一次 `dir` 继承。
  `transform:scaleX(-1)` 无差别翻所有图标、字符串拼接译文、只设 `dir` 漏 `lang` → 只翻方向性图标、改参数化消息 `t('greeting',{name})` 外置、`dir` 与 `lang` 同时输出。
- 必检：`dir` 与 `lang` 同设；locale 检测优先级「显式用户偏好 > URL 路径/子域 > `Accept-Language` > `navigator.languages`」、按特异性回退 `fr-CA→fr→默认`、不用 IP 地理定位（B）。
  膨胀预算德语 +30–35%(留 +40%)、芬兰语 +30–40%(留 +45%)、法语 +15–20%、西语 +20–25%、葡语 +20–30%、日中 −10~+5% 需更大字号（B）。
  预算数值属保留分歧：来源 1 逐语言细表(B) vs 来源 3/4 概括「+20–30%」「芬兰语/俄语 +40–50%」(B/D)，以前者为设计余量基准并保留更保守留白、不擅自取单值；`min-width` 而非 `width`、导航标签 1–2 词、错误信息先用德语测（B）。
  日期/货币/排序/复数走 `Intl.DateTimeFormat`/`NumberFormat`/`Collator`/`PluralRules` + CLDR 复数 1–6 种（B）；`<bdi>` 隔离动态数据、数字/URL/编码保持 LTR（A/B）。
  `aria-label`/状态文案随 locale 翻译按 HR-09、播报文案翻译按 HR-10，RTL 下焦点环与方向键/Home-End 语义翻转按 HR-03 / HR-04（A/B）。
