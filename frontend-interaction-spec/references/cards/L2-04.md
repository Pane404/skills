### L2-04 数字输入 / 步进器（Number Input / Spinbutton）

- 判断句：要键入精确数值、有 min/max 边界与 step 步进（数量、单价、阈值）用 Number Input（`spinbutton` 语义与可见 label 按 HR-09，+/− 命中按 HR-01）；
  卡号/邮编/电话等数字字符串改用 单行文本输入 Text Field，相对/粗略调节改用 滑块 Slider，少数离散预设改用 L1-08 Segmented / L2-16 Radio。
- 不用：卡号/邮编/电话/账号 → 单行文本输入 Text Field（`inputmode="numeric"`，替代）；音量/亮度/价格区间 → 滑块 Slider（替代）；1/5/10 条等少数预设 → L1-08 Segmented / L2-16 Radio（step 不是档位数）；含字母编码 → 单行文本输入 Text Field。
