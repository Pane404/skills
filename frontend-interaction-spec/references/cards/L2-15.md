### L2-15 复选框与半选（Checkbox / Indeterminate）

- 判断句：一组相互独立、可勾选 0..N 个（含半选）、结果在提交时生效用 Checkbox（原生 input + `fieldset`/`aria-checked` 三态按 HR-09，三态非颜色按 HR-02）；切换要立刻生效改用 L2-17 Switch，互斥唯一改用 L2-16 Radio，6+ 项长列表改用 多选 Multi-select。
- 不用：切换后要立即生效 → L2-17 Switch（替代）；一组互斥只能选一个 → L2-16 Radio Group（替代）；6+ 项且无搜索/过滤 → 多选 Multi-select；上方有「保存」却用 Switch 语义 → 改回 Checkbox（开关+Save 是矛盾）；父子级联整支 → 树选择 Tree Select。
