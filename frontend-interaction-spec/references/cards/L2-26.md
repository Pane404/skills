### L2-26 穿梭框 / 双列表（Transfer / Dual Listbox）

- 判断句：大候选池 + 小已选集、需要把已选集当清单回读/排序用 Transfer（双 `listbox` 语义按 HR-09，搬运后焦点归还按 HR-04，结果播报按 HR-10）；只选一个改用 L2-11 Select，<5 项改用 L2-15 Checkbox Group，不需回读已选集改用 多选 Multi-select，选项是树/层级改用 树选择 Tree Select。
- 不用：只选一个值 → L2-11 Select / Listbox（替代）；候选 <5 项或每列很短 → L2-15 Checkbox Group / Combobox；不需要回读「已选集」→ 多选 Multi-select（chips）；空间受限/窄屏放不下两列 → 单列+过滤+已选计数；用于导航/命令/单选字段 → 对应导航/菜单/Select（替代）。
