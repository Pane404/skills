### L3-09 空状态（Empty State）

- 判断句：请求已完成且结果确实为零才用 EmptyState（「Loading 是状态，Empty 是结果」），答「什么空了/为什么空/下一步」并给一个明确主行动；A 还是 B：pending 用 Skeleton/Spinner、rejected 用 ErrorState、resolved 且为空才用它（绝不把失败渲染成空）；`Empty ≠ No-results`，五种子型分别设计。
- 用：新注册用户第一次打开「项目」列表，因为是首次零数据、产品第一印象，需说明「这里将放什么」并给「创建第一个项目 / 导入 CSV」主行动（A/B）；搜索「蓝色沙发」叠加 3 个筛选后 0 命中，因为是有数据但被条件排除，需回显查询词/生效筛选并给「清除筛选 / 放宽日期 / 检查拼写」（B）。
- 不用：内容仍在加载 → Skeleton / Spinner（空状态必须 gate 在「resolved」之后，A）、请求失败/超时/离线 → ErrorState 带重试（替代，绝不把失败渲染成空，防用户重复录入，A）；no-results 套用 first-use 文案、或无权却给「创建」主按钮 → 按子型分别设计 / 说明角色 + 申请权限路径（替代，B）。
- 必检：五种子型分别设计：first-use / no-results / cleared(成功) / permission / setup-prerequisite，另 error-unavailable 应转 ErrorState，不可共用一句「暂无数据」（A/B）。
  分类口径属保留分歧，各方取值：Cognite 把 error/permission/配置缺失都列入 EmptyState(B) vs IC Design System / techbloat / UXPG「失败必须走 ErrorState、不得渲染成空」(A)，取后者、状态机与语义必须分离、不调和。
  gate 在 resolved data status 之后渲染、保留表头/筛选器/上下文、一个聚焦主 CTA（描述性标签而非「点击这里」）、次 CTA 不与主行动竞争、CTA ≤ 2 个（A/B）。
  body ≤ 3 行、标题句末不加标点、body 句号结尾、插画情境匹配且 `alt=""` / `aria-hidden="true"`（B/D）；无权限不给做不到的按钮、给解释或申请路径（B）。
  异步空结果可用 `role="status"`播报一次（SC 4.1.3，A）。失败转到 L3-10，按 HR-10 确定播报优先级。
  重试时保留筛选、缩放、滚动与已填输入，局部刷新并禁用重试按钮防重复（B）。
  对比度按 HR-02、触控按 HR-01、ARIA 状态显式按 HR-09、动效与播报按 HR-10；出现不抢焦点、保持逻辑 Tab 顺序与可见焦点态（A）。
- 契约：非模态；C1–C6 不适用（结论态内容区、不抢焦点、背景可交互）｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
