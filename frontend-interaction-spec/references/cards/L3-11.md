### L3-11 结果页 / 完成页（Result / Confirmation Page）

- 判断句：要「持久凭证 / 后续时机 / 可收藏打印」才用整页结果页（旅程终点）；Confirmation Page ≠ 就地 Success Confirmation（任务未结束的就地证明）≠ Toast（瞬时），小额成功或仍在任务中都不升级成整页。
- 用：电商支付成功给订单号 SO-0918/金额/支付方式、政府申请给参考号 HDJ2123F——因用户要把页面当收据收藏引用、且需知道发货/处理机关与时机；后台长任务结束给「处理中」状态 + ETA + 去哪查进度。
- 不用：① 保存/复制/收藏等小额低后果成功、需撤销的删除一条 → 就地状态 / L3-03 Toast / L3-04 Snackbar+Undo（替代）；② 结果尚未权威提交、用户已离开才到达 → L3-06·L3-08 / L3-05 通知中心（替代）；别在请求完成前显示「成功」。
- 必检：权威提交后才路由、有独立 URL 可刷新/收藏/打印；必备完成标题 + 参考号（含用途）+ What happens next（谁/何时/是否需再操作）+ 联系方式 + 保存/打印 + 反馈链接（A/B）；内容居中 max-width ≈480px（B）。
  PRG / 幂等键保证刷新与 Back 不重放提交、失败版给原因 + 数据是否保留（如 30 分钟）+ 重试/换方式（B/D）；`<main>` + 单一 `<h1>`、进入后焦点移到标题、图标 `aria-hidden`（A）；绿色面板内交互元素另验对比与焦点按 HR-02 / HR-03，播报与动效按 HR-04 / HR-10。
- 契约：非模态（整页路由跳转、非浮层）；C1–C6 不适用｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)
