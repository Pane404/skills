### L3-12 状态点与在线状态（Status Dot / Presence）

- 判断句：持续稳态、空间紧、含义已在旁边文字里 → Status Dot（只做一眼可辨的重复提示）；它不承载解释/计数/动作/事件，要数字→Badge、要解释要行动→L3-01、瞬时事件→L3-03/L3-13、加载→L3-07。
- 用：聊天/协作列表每个头像角标在线/离开/忙碌/离线（判断能否现在打扰、需一眼扫过）；服务健康面板标正常/降级/故障、图表图例标系列——因是稳态常驻且与名称/图例文字成对，点+文字最省空间。
- 不用：① 有后果需解释/需行动（支付失败、权限不足）、要计数/未读数 → L3-01 Alert / 徽标 数字 Badge（替代）；② 瞬时事件、加载中、无人能据以行动的纯装饰 presence → L3-03·L3-13 / L3-07 / 直接去掉（替代）。
- 必检：默认 8px、密集 6px、超密 4px，与背景 ≥3:1 且浅底加 1px 深环、头像上白描边环（B）；绝不只靠颜色，用形状/填充双编码（在线实心/离开空心环/忙碌横杠/离线灰，B）。
  带文字点 `aria-hidden="true"`、独立点 `role="img"`+`aria-label` 或 polite status + 隐藏标签，状态变化须同步改文本才播报、静态多点关 live region（B）；默认不可聚焦不进 Tab、`pulse` 一次只用一个且静止不动画（B）。
  对比按 HR-02、播报/reduced-motion 按 HR-10、hover 等价路径按 HR-07。
