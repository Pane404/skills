### L3-13 同步状态（Sync Status / Offline State）

- 判断句：断网/重连/排队/冲突期间用一组诚实持续状态回答「工作安不安全、看到的是不是最新」（全局轻 Banner + per-item 状态）；铁律「已保存在此设备 ≠ 已同步」，全站通告→L3-02、单次操作失败→L3-10、瞬时成功→L3-03。
- 用：外勤地下室填完工单先本地保存后同步（须写「已保存在此设备，联网后同步」否则以为白干）；文档断网续打恢复后合并、弱网两人改同一张卡片——因是持续编辑/排队写入/可能冲突，需区分本地草稿/同步中/已同步/冲突并保留队列可见。
- 不用：① 全屏「无网络连接」挡住已加载内容、单次操作失败却泛化成全局离线 → 非阻断轻 Banner 保持内容可读可编辑 / L3-10 ErrorState（替代）；② 把「本机已保存」谎称「已同步」、用 queued writes 技术黑话、last-write-wins 覆盖地址价格长文本 → 六态白话文案 / field-level merge 或人工冲突解决（替代）。
- 必检：六态封闭集 Online / Offline(已保存在此设备) / Reconnecting / Syncing / Synced / Needs attention（仅须决策时出现）（B）；缓存带 last-updated、价格/库存/余额加陈旧警示、断网只禁在线专属动作并给导出本地副本替代（B）。
  先写本地库，操作进持久化 outbox（客户端 ID/幂等键），重连后按服务端顺序同步（B/D）。LWW 仅用于低风险字段，其他按字段合并或让用户处理冲突。
  核实本地持久化后再提示草稿已保留。失败和冲突持续可见，常规用 polite，紧急且需立即行动时用 assertive。连接抖动时合并播报（HR-10），对比和焦点按 HR-02 / HR-04。
