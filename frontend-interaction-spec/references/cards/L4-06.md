### L4-06 气泡卡片（Popover）

- 判断句：组 C 二级键=「通用富内容面板」（可含表单域/筛选/链接，非内置 OK/Cancel 的 L4-04），click 打开、点外/Esc 即关的轻关闭、不自动超时；「内容里有没有可点的东西？」有→本条、只有一句纯文本→L4-07 Tooltip、要打断整页交付任务→L4-01 Dialog。
- 用：表格列设置（显示/隐藏列+排序）小面板（锚定、多控件、不值得打断整页）；尺寸设置四个输入框或日期范围筛选（边看背景结果边调条件、不阻断背景，B）。
- 不用：2–12 词短标签/图标释义 → L4-07 Tooltip、有提交/保存或多步表单 → L4-01 Dialog（替代）；内容长/需 URL → L4-16 Drawer 或页面、只是二次确认 → L4-04 Popconfirm（替代）。
- 必检：触发器是真实可聚焦元素（button/a）+ `aria-expanded` 随开合更新；`aria-haspopup` **按弹出内容角色取值**（menu / listbox / tree / grid / dialog），
  普通富内容面板不设或按实际角色设，**禁无条件 `true`**（B）；无 `aria-modal="true"`、默认不困焦点、不锁 body 滚动（A/B）；Esc 只关最顶层、点外/Esc/关闭后焦点归还触发者按 HR-05 / HR-04（A）。
  无最终提交/保存按钮与多步流程、关键信息在页面正文有冗余、不挂非交互元素背后（B）；常用宽 280–360px、固定档 192–640px（B）；触控目标按 HR-01（A）。
  轻关闭监听用 `pointerdown` 而非 `click` 按 HR-05（D）；12 方位 placement 贴边 flip/shift（D）；`modal` 默认值冲突已裁定（台账 #6）：默认不困焦点，显式 `modal=true` 时须按完整模态契约核对 C5 背景 inert 与 C6 滚动锁，不再标「不适用」（B）。
- 契约：默认非模态 click 锚定（轻关闭）；C1 适用（弱化）/C2 默认不适用（显式 `modal=true` 时按模态完整核对 C1–C6，含 C5 / C6）/C3 适用/C4 适用。
  可含搜索·过滤输入框按「含表单或多步」口径，注明不提交/非数据表单｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
