### L4-07 文字提示（Tooltip）

- 判断句：「内容里有 tab 停靠点吗？」有→不是 Tooltip；「用户不看它能不能完成任务？」不能→也不该是。本条只放纯文本、可选、补充的一小句，`role="tooltip"` 永不获焦。
- 用：纯图标工具栏按钮释义（垃圾桶=删除、齿轮=设置，补可访问名）；快捷键提示 `⌘K`、缩写 ROI 一次性解释（非关键、不读也不影响完成任务）。
- 不用：必读信息（密码规则、必填说明）→ 就地可见 helper text / inline validation、内容含链接/按钮/输入框 → L4-06 Popover 或 L4-01 Dialog（替代）；需结构化预览 → L4-09 HoverCard、触屏为主且信息关键 → 直接放可见标签/正文（替代）。
- 必检：容器 `role="tooltip"`+id、触发器上 `aria-describedby` 指向它（无 `aria-haspopup`/`aria-expanded`/`aria-modal`，A）；tooltip 内无任何可聚焦元素、焦点永不移入、Esc 关闭不移动焦点（A）。
  满足 WCAG 1.4.13 三条件：Esc 可关、指针能移入浮层不消失（closeDelay+safePolygon）、无自动超时（A）；建议 ≤150 字符（B）。
  hover 延迟按 HR-07（台账 #8，具体随库；原篇打开 300–600ms/关闭 ~150ms、focus 立即打开、blur 关闭，B/D）；触发元素键盘可聚焦（button/a 或 `tabIndex=0`）按 HR-09、贴边自动 flip（A/D）。
  关键信息未只放 tooltip、触屏/读屏有可见等价路径，按 HR-07（A）。
- 契约：非模态、非焦点型 hover/focus 增强；C1 不适用/C2 不适用/C3 适用（Esc 不移动焦点）/C4 天然满足/C5 不适用/C6 不适用｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
