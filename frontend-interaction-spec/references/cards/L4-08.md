### L4-08 Peek 悬停实体预览（Anvil pattern / Peek）

- 判断句：先消歧——说「peek」问四义 ① Anvil hover 实体预览 ② HoverCard/Quick View（见 L4-09）③ 底部抽屉 peek 档（见 L4-18）④ Arc 链接预览；本条主语义=①，是 pattern 非可 import 组件，铁律「绝不承载独家信息」，详见 [glossary.md](../index/glossary.md)。
- 用：悬停客户名预览余额与最近活动（点进详情页同样能拿到、只省一次跳转）；悬停「Jane Doe」显示资料 + Call/Email/Message 快捷动作（详情页同样可用）。
- 不用：独家信息/操作 → 信息回详情页或改 L4-06 Popover（click、可聚焦）、放输入框/过滤/多步 → L4-01 Dialog 或目标页（替代）；当键盘/读屏/触屏唯一入口 → 点触发器进详情页 + 触屏 tap 等价（替代）。
- 必检：① 已消歧为 Anvil Peek、用 Popover 拼装未造 `<Peek>`（B）；① 外层 ≤360×540px、内容 ≤328×508px（16px padding，B）；触发元素是 action/link、默认不困焦点、不响应 focus、延迟按 HR-07（B）；绝不承载独家信息、内无输入框/过滤/多步、最多 call/email/message 简单快捷动作（B）。
  给触屏 tap 与键盘「点进详情页」等价路径按 HR-07、Esc 只关本层不连带关父层按 HR-05、背景未 `inert` 未锁滚动、关闭后焦点仍在触发者按 HR-04（A/B）。
  尺寸属保留分歧（台账 #9），须列各方不调和：Anvil ≤360×540(B)/HoverCard 260–320px(B)/peek 档 72–96px(B)/True Sheet 150px(D)，按语义分型。
  hover 延迟按 HR-07（台账 #8，随库；原篇 Anvil 用默认、Radix 700/300、Dialtone 300，A/B）；`modal` 默认值已裁定（台账 #6）：code 页标 true(B) 与 prose 冲突，以 prose 为准「默认不困焦点」。
- 契约：非模态 hover 增强；C1 不适用（但须给等价路径）/C2 禁止默认启用/C3 适用/C4 弱化/C5 不适用/C6 不适用｜详见 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
