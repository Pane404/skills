### L4-10 快速预览（Quick View）

- 判断句：先消歧两形态——A 锚定 hover 非模态卡 / B 模态 lightbox（带变体与加购，居中覆盖；移动端全屏铺满仍归居中覆盖），本卡按主语义形态 B 判定；铁律「Quick View 是 shortcut 不是详情页替代，必给 View Full Details」，见包内 [glossary.md](../index/glossary.md)。
- 用：服装/鞋履/家居等视觉驱动型列表点 Quick View 看大图、选颜色尺码直接加购，因看图即可决策、不必往返详情页（B）；留在列表保留滚动与筛选位置、连续速览 5–6 件不丢上下文（B）。
- 不用：规格驱动型商品（笔记本/家电/工具/配件）或 3+ 变体轴、尺码表、兼容性清单 → 直接进详情页并改进列表卡片信息；想用它替代详情页、掩盖缩略图过小或把必读规格只放浮层 → 把列表项缩略图与属性做对、信息回详情页（B）。
- 必检：给 `role="dialog"` 并按 HR-06 定模态性，必留 View Full Details 出口 + 大号关闭键 + Esc（HR-05，A/B）。
  设 <0.5s 显示、数据 100–300ms 到且有 skeleton、`@media (hover:none)` 触发按钮常显、加购后跳购物车 UI 不静默关闭（B/D）；遇 3+ 变体轴或需尺码表直接跳详情页、变体按 variant ID 存（B）。
  点遮罩关闭属保留分歧——Polaris 一律不 / Radix 默认可 / iOS·Android 各异，按第②层随技术栈定、不擅自取单值（B/D）。
- 契约：形态 B 模态（C1–C6 全满足；Esc 只关本层）；形态 A 非模态 hover 增强（C1/C2/C5/C6 不适用、C3 适用、C4 弱化）｜详见包内 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
