### L4-12 动作菜单（Action Menu）

- 判断句：「有可见触发按钮、3–12 个就地命令」→ 动作菜单；与 L4-11 是同一组件族，本卡只取内容组织视角（放什么/怎么排），键盘/ARIA 契约复用 L4-11，选中/Esc/点外即关且不自动超时。
- 用：文件/发票行「⋯」打开/复制 ID/置顶/删除、文档 6–7 个同族命令用 Separator 分组且破坏性项置底，因长尾命令不必常驻、序列位置更好记（B/D）；工具栏溢出把次要动作收进「更多」、账户菜单用 Label 分组，因主操作仍可见（B）。
- 不用：主要/高频操作被藏进菜单或只有 1–4 个命令 → 保持可见的带文字按钮/内联按钮；50+ 命令需靠回忆名字、或选一个持久值 → Command Palette / Select（B/D）。
- 必检：控就地命令 3–12 个（B），并给数量阶梯 1–4 内联 / 5–8 下拉 / 9–15 分组标题 / 16–50 加搜索 / 50+ 转命令面板（社区实践 D，不作官方依据）；设 item ≥32px（移动端触控按 HR-01）、子菜单最多一层约 5 项、顶栏 5–7 项以内、min 宽 160–200px（B/D）。
  把破坏性项排在分隔线之后并接确认，保持同一命令在按钮/行 ⋯/右键/快捷键入口的动词·图标·快捷键·启用态一致、每个命令界面别处可达（B）。
  移动端主溢出改 Action Sheet/Bottom Sheet、hover-only 图标给键盘/触屏等价（HR-07，B/D）。
- 契约：非模态 `role=menu` 命令列（C1/C3/C4 适用，C2/C5/C6 不适用；「…」项先关菜单再开 Dialog、Esc 不连带关父层）｜详见包内 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
