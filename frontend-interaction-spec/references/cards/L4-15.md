### L4-15 命令面板（Command Palette）

- 判断句：「命令多到要靠打字回忆、且跨页面/动作/内容一起搜（50+）」→ Command Palette；Esc/点外/选中命令即关不自动超时，它是 Dialog 的键盘加速器特化，含搜索输入按「含表单或多步」计但不提交、非数据表单。
- 用：SaaS 后台 100+ 动作与页面、熟练用户全程键盘（⌘K 模糊匹配把扫描菜单变回忆名字）（B/D）；跨应用跳转「账单」直达 Billing、嵌套 pages「Move issue ›」逐级回退，因一条查询跨 Actions/Navigation/Files 分组（B/D）。
- 不用：筛选某个具体列表/数据集、或表单里从已知集合选值 → 专用页内搜索/筛选栏 / Combobox；只有 5–8 个命令、或命令只在 Palette 里存在 → Action Menu/可见按钮，并把命令镜像到菜单·工具栏·详情页（B/D）。
- 必检：给 `role="dialog"`（按 HR-06 定模态性、按 HR-09 补可访问名）、输入 `role="combobox"`+`aria-activedescendant` 指向高亮 option、结果 `listbox`/`option`，禁用 roving tabindex 以免抢走输入焦点（A/B/D）。
  让 ⌘K/Ctrl+K 监听忽略可编辑字段并 preventDefault、页面留可见启动按钮、触屏改可见搜索按钮 + slide-up sheet（B/D）；控可见结果 6–8 项后滚动、空查询露 Recents 5–10 项、空态含查询词、结果计数 `aria-live="polite"`（HR-10，B/D）。
  设打开 <100–200ms、动效 <200ms 或按 HR-10 跳过、异步 debounce 200ms + AbortController（各家 <100/<200ms 不等，按原篇并写不取单值）（B/D）。
  保证每条命令别处可达、破坏性命令选中后接确认、一页只挂一个 CommandDialog（B/D）。
- 契约：模态 Dialog（C1–C6 全满足；C1 打开即聚焦搜索输入保持 combobox 语义、C3 嵌套 pages 逐级回退只关本层）；含搜索输入但**不提交 / 非数据表单**｜详见包内 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
