### L4-16 抽屉 / 侧边面板（Drawer / Sheet）

- 判断句：先问「背景要不要继续操作」：要 → 默认非模态并排面板 / 布局；只需可见但不操作 → 非模态 Drawer；必须阻断背景才用模态式 Drawer（scrim + inert + 焦点困住真的生效）。屏幕边缘附着按「页面内就地」归并，直到显式关闭 / Esc / 点遮罩不自动超时；含未保存表单禁用轻关闭。
- 用：点表格行右侧滑出订单详情 + 操作历史 + 编辑，因要边看列表边操作、关掉回到原选中行，默认非模态（B/D）；商品列表高级筛选让左侧结果实时更新、购物车侧滑面板，因需参照主内容调条件（B/D）；只有必须当场表态才升级模态抽屉。
- 不用：仅并排核对却被做成背景 inert 的模态抽屉 → 改非模态面板 / 布局；决策阻断 / 破坏性（删除确认）→ Dialog / Confirmation Dialog；需独立 URL / 打印或只有一句话 → 页面或路由 / Popover·Tooltip（B/D）。
- 必检：给 `role="dialog"`（按 HR-06 定模态性）+ 按 HR-09 命名当前对象，设桌面宽 320–480px、scrim 约 rgba(0,0,0,0.4)、body 区独立滚动且 header/footer 固定、`overscroll-behavior:contain`（B/D）。
  留可见关闭按钮 + Esc（HR-05）、按 HR-04 归还触发行焦点并恢复筛选/滚动/选中态、含未保存表单禁用点遮罩关闭或加丢弃确认（B/D）；禁抽屉嵌套超过两层、窄屏改全屏/Bottom Sheet、RTL 锚定边镜像（B/D）。
  点遮罩关闭属保留分歧——Polaris 一律不 / Radix 默认可 / iOS·Android 各异，按是否含未保存数据分型、不擅自取单值（B/D）。
- 契约：默认非模态并排（C1 / C3 / C4 适用，C2 / C5 / C6 不适用）；显式启用模态时才 C1–C6 全满足，含 C5 背景 inert、C6 滚动锁。
  C3 含表单走 guarded closing、C4 归还触发行并恢复筛选 / 滚动 / 选中态｜详见包内 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
