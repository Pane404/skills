### L4-19 动作面板（移动端）（Action Sheet）

- 判断句：用户主动做了一个动作、需要 2–3 个相关分支（可能含破坏性）→ iOS 底部模态动作面板；系统突然要你回应 → AlertDialog；要放内容/长列表/分档 → Bottom Sheet。
- 用：iPhone 取消编辑给「删除草稿/保存草稿/取消」三选、点分享列目标，因为 alert 只给确认/取消、给不了额外分支；删除前给「删除/归档/取消」比纯二选更贴合用户目标。
- 不用：系统主动告警/只需确认取消两按钮 → 改 AlertDialog / Confirmation Dialog；长列表/滚动/表单/多步或桌面 Web → 改 Bottom Sheet / Drawer / Dropdown Menu / Dialog（按钮 >4 个也精简或改 Bottom Sheet）。
- 必检：≤4 个按钮（含 Cancel，额外 ≤3，B/Apple HIG）、按钮命中区按 HR-01、标题一行、无滚动/输入/长内容；Cancel 必需置底且与其他项分离（watchOS 左上）、destructive 置顶且标签写清对象（不靠红色）；
  `role="dialog"`+`aria-modal="true"`+背景 inert+Tab 循环+Esc 只关本层+关闭后焦点归还触发控件+锁滚动补宽度（HR-06 / HR-05 / HR-04，A/D）；iOS 26+/iPad 绑触发控件（spring/popover 锚定）；
  Cancel/关闭出口不计入 F5 内容动作；点遮罩关闭属台账保留分歧，各方取值：iOS 不关（B/HIG）、Android·iPad popover 点外取消、Polaris 一律不、Radix 默认可（B/D），按平台与技术栈定、不调和。
