### L4-20 图片/媒体预览层（Lightbox）

- 判断句：只想把媒体放大看（可翻页/缩放）→ 暗色全屏 Lightbox；放大看是为了买/选规格 → Quick View；放大是为了填一堆字段 → Full-screen Dialog / 页面；模态由 `showModal()` 定、不由暗色遮罩定。
- 用：婚礼/作品集照片网格点缩略图全屏看大图 + caption + 「2 of 6」计数翻页，因为不离开页面、不丢滚动位置；电商商品图放大看织物纹理，因为 fitted 尺寸看不清、需围绕指针缩放。
- 不用：单图无翻页缩放/营销订阅弹窗 → 直接内联显示或页内模块 / Interstitial；多步表单/连续决策/需 URL 深链/要边看边参照页面 → 改页面、Full-screen Dialog、Drawer 或详情页/路由。
- 必检：用 `<dialog>.showModal()`（A，MDN/HTML）取 top layer+背景 inert+焦点困住+Esc+`::backdrop`+焦点归还（HR-06 / HR-05 / HR-04），容器 `role="dialog"`+`aria-modal="true"`+可访问名；
  缩略图是真 `<button>`/`<a>` 且无 JS 也能开大图（HR-09）、每张图非空描述性 alt；
  关闭后焦点还「最后显示的那张」缩略图（items[current].focus()）而非第一张；多出口（Esc/点暗区仅 e.target===dialog/可见关闭）+ ←/→ 翻页 + `+/-/0` 缩放 + `aria-live="polite"` 播报「Image N of M」（HR-10）；
  端点用 `aria-disabled` 而非 `disabled`（D，HR-09）；`object-fit:contain`、宽 ≤90vw/高 ≤85vh 不溢出、锁滚动补偿宽度（B/D，HR-06）；翻页/缩放/关闭为查看器控件、不计入 F5 内容动作。
- 契约：模态（`showModal()` 定，C1–C6 全满足；非由暗色遮罩定）｜详见包内 [contracts/overlay-contract.md](../contracts/overlay-contract.md)。
