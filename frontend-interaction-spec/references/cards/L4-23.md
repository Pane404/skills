### L4-23 插页 / 侵入式弹层（Interstitial）

- 判断句：「是两件事之间的暂停，还是用户要做的一件事？」前者 → Interstitial（系统按内容断点插入、全屏接管、必须能立刻跳过、限频合规）；后者 → Full-screen Dialog / 页面；只是想让人知道 → Banner。
- 用：游戏一关结束先显示得分后插一条静态/视频、阅读类 App 文章与文章之间插入，因为是用户已理解为「暂停」的自然断点、不盖掉胜利反馈；完成一次任务/交易后的过渡层，因为是已完成动作后的自然 pause、不打断进行中的意图。
- 不用：App 加载/退出、点击后动作生效前、表单/阅读/专注任务中 → 只在内容断点插入或取消（禁止 surprise）；连续流应用/快速工具/移动 Web 首页/首启全屏轮播 → 改 banner、非打断式变现、Hotspot 或 Banner（SEO/Better Ads 抑制风险）。
- 必检：15 秒内必须可关闭（A/B，Google Play 政策；政策具时效性、以官方当前措辞为准，opt-in/不打断者可超时）；关闭/跳过按钮真实可见 ≥48dp、不伪装成内容/不被遮挡/与 CTA 分开（B/D）；
  频控每两次用户操作 ≤1 次、不连续两条、冷却+每会话上限+新用户宽限期+素材预加载（B，AdMob）；`role="dialog"`+`aria-modal="true"`+可访问名「广告」+背景 inert+Tab 困住+锁滚动补宽度（HR-06，A/D）；
  焦点移入（优先关闭/跳过）、Esc/Android Back 只关本层、关闭后焦点与滚动位置复原且不丢任务状态（HR-04 / HR-05）；一条 headline + 一个 CTA、2 秒读懂、标注「广告」、viewability ≥50% 像素可见 ≥1 秒（D，IAB）；关闭/跳过为模态出口、不计入 F5 内容动作。
