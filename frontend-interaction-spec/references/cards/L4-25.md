### L4-25 原生浮层语义 popover vs showModal（Popover API vs Dialog）

- 判断句：先消歧——设计术语 popover＝L4-06 气泡卡片组件，Popover API＝浏览器机制（本条主语义）；内部 3 种 API 主选（`popover` 非模态，按 auto / manual / hint 分型、`dialog.show()` 非模态、`dialog.showModal()` 模态），按主语义 `popover=auto` 判定；
  auto 点外/Esc/开另一个 auto 即轻关闭、不自动超时；原生 API 决定原生 Dialog 是否模态，指向包内 [glossary.md](../index/glossary.md)。
- 用：背景需可点 → `popover`（菜单/筛选/combobox 用 `"auto"` 轻关闭、Toast/Undo/持久帮助用 `"manual"`、Tooltip 叠已开菜单用 `"hint"`）或 `dialog.show()`/`<dialog popover>`（需 dialog 语义但不阻断，须自补显式关闭），因为零 JS 拿 top layer 且页面保持可用；
  背景必须停止响应且须回答（删除确认/付款/必答表单）→ `dialog.showModal()`，因为背景 inert + 焦点困住 + 隐式 `aria-modal` + `method="dialog"` 拿 `returnValue`。
- 不用：想用 popover+半透明遮罩/`backdrop-filter` 冒充模态、或确认/破坏性/登录用 popover → 改 `showModal()`（遮罩样式不产生模态，A/MDN、Sekin）、toast/常驻面板误用 auto → 改 `popover="manual"`、Tooltip/菜单误用 `showModal()` →
  改 `popover="auto"/"hint"`；用 `dialog.show()` 搭菜单 → 改 `popover="auto"`、给 `<dialog>` 加 `tabindex` 或靠 `role="dialog"` 手写模态 → 交给 `showModal()`、`hint` 当全平台可用 → 按浏览器支持检测，回退到有显式关闭的 manual（A/MDN）。
- 必检：先按「背景是否必须停止响应」选 API、不从遮罩反推（A/MDN「Popovers … are always non-modal」）；popover 一律无 `aria-modal="true"`/不困焦点/不锁背景滚动，`showModal()` 才 inert+焦点困住+隐式 `aria-modal`+top layer（HR-06，A）；
  `popover="manual"` 与 `dialog.show()` 默认不响应 Esc/不轻关闭；缺省 Auto 对非模态 Dialog 表现为 None→ 必须给可见关闭按钮（A）；`auto` 打开可按 autofocus 处理；菜单按其键盘模式补焦点与方向键（A/D）；Esc 只关最顶层、不连带关父层、关闭后焦点归还触发者（HR-05 / HR-04）；
  `<dialog>` 不加 `tabindex`、有可访问名、破坏性确认 `autofocus` 在 Cancel（A，HR-09）；`showModal()` 成功会关掉已开 auto popovers、`hint` 按浏览器能力渐进增强（A/D）。
- 契约：非模态按模式核对 C1/C3/C4；C2、C5、C6 不适用。模态 `showModal()` 有聚焦步骤与背景 inert；C1–C5 逐项核对，C6 单独实现并验证｜见 [浮层契约](../contracts/overlay-contract.md)。
