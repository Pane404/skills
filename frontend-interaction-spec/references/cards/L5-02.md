### L5-02 侧边导航（Sidebar Navigation / Navigation Drawer）

- 判断句：5+ 顶级目的地或 2+ 层级、桌面宽屏用常驻侧栏（`<nav aria-label>` 与当前项 `aria-current="page"` 按 HR-09，Modal 焦点归还按 HR-04 / HR-06）；≤2 个目的地改用 L5-05 Tabs、3–5 个改用 L5-04 底部导航 / 导航栏 Rail，同一屏只留一个主导航、切断点只变形不换标签。
- 不用：3–5 个同级目的地 → L5-04 底部导航 / 导航栏 Navigation Rail（替代）；装当前行详情/编辑表单 → L4-16 内容抽屉（替代）；目的地需频繁来回切换 → 底部导航/Tabs（隐藏导航降发现率）。
  M3 Expressive 从零起新项目 → 导航栏 expanded rail（替代）；「drawer 是否弃用」保留分歧（M3 官方(B)弃用 vs 其他系统仍用，按第②层平台约定随技术栈决定，不调和）。
