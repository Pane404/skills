### L5-04 底部导航（Bottom Navigation / Navigation Bar）

- 判断句：compact 窄屏、3–5 个同等重要且互不隶属的顶级「地方」、每项都是导航目的地而非动作才用底部导航；同一对象不同视图用 L5-05 Tabs、屏幕变宽转 导航栏 Rail / L5-02 侧栏；当前态与可见标签按 HR-09、触控按 HR-01。
- 不用：<3 个目的地 → L5-05 Tabs；>5 个 → 导航栏 Rail / L5-02 侧栏抽屉或 More；单一任务页（撰写/全屏播放/设置）→ 隐藏底栏走独立页面，2 级以上层级回溯 → 面包屑 面包屑 + 侧栏；新建/删除/筛选等动作 → L1-05 FAB / 工具栏 Toolbar / L4-19 动作面板；大屏仍用底栏 → Rail / 常驻侧栏。
