### L5-05 标签页（Tabs）

- 判断句：切完仍在「同一个地方」、只是换一面的同级互斥视图才用 Tabs（页内 aria-selected、不改 URL）；改 URL/整页导航 → `<nav>` 链接（L5-02 / L5-04）、去互不相关顶级区 → L5-04 底部导航 / 导航栏 Rail / L5-02 侧栏、必须按顺序走完 → 步骤条 Wizard；选中态与焦点归还按 HR-09 / HR-04。
- 不用：每个 tab 其实是独立页面/路由（点它会改 URL、文档标题或整页刷新）→ `<nav>` + 链接 + aria-current="page"（L5-02 / L5-04）；2–4 个互斥视图模式/筛选（List/Map、日/周/月）→ L1-08 Segmented Control / 筛选栏 筛选栏；
  有先后顺序的流程或长表单依次填 → 步骤条 Steps / L8-13 多步表单；tab 多到换行第二行 → 横向可滚动 tabs 或 导航菜单 巨型菜单。
