### L5-08 加载更多 / 无限滚动（Load More / Infinite Scroll）

- 判断句：只有无目标浏览（社交 feed / 短视频 / 照片墙，位置无意义）才允许无限滚动，且必须先补齐返回位置恢复与键盘逃生通道，缺一即改用分页或 Load More；有定位需求用 L5-07 分页、低摩擦又要页脚/进度用 Load More（更安全默认）；role="feed" 与播报按 HR-09 / HR-10。
- 不用：搜索结果 / 比价 / 找特定项 / 回到已知位置 → L5-07 分页（无限滚动对搜索结果有害）；页脚含法律/客服/无障碍声明 → 改 Load More 或把 footer 移 sticky；要分享/收藏/刷新恢复却不同步 URL → 同步 ?page=N / ?after= 或改分页；
  需被索引的深层条目 → 暴露真 `<a href>` 分页 URL + sitemap；DOM 无限增长不虚拟化 → 虚拟列表 虚拟列表。
