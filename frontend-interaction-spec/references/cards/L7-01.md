### L7-01 折叠面板（Accordion / Collapse）

- 判断句：一组同层级、可独立并存展开的次要/可选段落才用 Accordion（先扫标题、按需展开、减少长页滚动），完成任务必需的内容绝不藏进折叠；单块显隐 → L7-02 Disclosure、互斥视图 → L5-05 Tabs、顺序流程 → 步骤条 Stepper；真按钮与 aria-expanded 按 HR-09、焦点环按 HR-03。
- 不用：必填字段/错误/价格/条款等任务必需信息 → 直接常显；顺序通读或跨段对照 → 平铺标题+正文或 L5-05 Tabs；只有 2–3 段 → 直接平铺；拿它当页面导航 → L5-02 侧栏 / Navbar；顺序式表单步骤 → 步骤条 Stepper / L8-13 多步表单；需页内搜索/深链 → 内容留 DOM 或展开态写进 URL；超过一层嵌套 → 拆平级分组。
