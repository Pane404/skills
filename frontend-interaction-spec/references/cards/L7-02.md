### L7-02 就地展开（Disclosure）

- 判断句：一个真按钮在原地显隐一块「只有部分用户需要的可选补充」才用 Disclosure（不切面板、不改路由、不开浮层），做对决策/完成任务必需的信息一律常显；
  一组带标题段落 → L7-01 Accordion、同级互斥视图 → L5-05 Tabs、盖住页面做独立任务 → L4-01 Modal / L4-16 Drawer；aria-expanded 与焦点停留按 HR-09 / HR-04。
- 不用：费用/警告/错误/资格/必填字段等必需信息 → 直接常显在主要内容；多段分组或多个独立 section → L7-01 Accordion / L5-05 Tabs；需独立 URL / 深链 / 分享 / 打印 → L8-10 详情页 / 路由驱动弹窗 URL 驱动弹窗；
  内容很短收起只省一两行 → 直接显示；需阻断/聚焦的独立任务 → L4-01 Modal / L4-16 Drawer；hover/focus 才触发 → 改显式点击按钮；第三层嵌套 → 重组功能。
