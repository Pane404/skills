### L7-03 行内编辑（Inline Editing）

- 判断句：单值、低风险、易撤销且周围页面就够判断才就地编辑（阅读态↔编辑态共用同一盒子、不离开页面）；不可逆/高影响/批量/跨记录改动 → L4-03 确认对话框 / L8-10 详情页审阅、多字段联动/依赖/预览 → 表单容器 表单 / L8-18 表单页 / L8-13 多步表单、需解释/次要控件 → L4-01 Modal；焦点归还与播报按 HR-04 / HR-10。
- 不用：删除/退款/权限/对外发布/金额结算/库存扣减 → L4-03 确认对话框或 L8-10 详情页走提交前审阅；五六字段联动校验/依赖/提交前预览 → L8-18 表单页 / L8-13 多步表单；
  点击该值已触发下钻/选中/行选择 → 独立编辑入口（行操作菜单/详情页）；需独立 URL/稍后继续 → Modal 或整页；可编辑性只靠 hover → 常显编辑控件；移动端窄屏 → 底部 sheet / 详情页。
