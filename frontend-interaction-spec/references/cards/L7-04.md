### L7-04 主从布局（Master-Detail / List-Detail）

- 判断句：列表选中驱动一块可独立成页的详情、且要在宽窄屏都保住位置才用 Master-Detail（宽屏并排、窄屏降级为列表页↔详情路由页 + Back）；
  详情只是简短相邻检查器 → 分栏面板 Inspector、详情临时办完即关 → L4-16 Drawer、无稳定选中项 → Feed 网格 / 单列列表、次要内容贴着主内容才有意义 → Supporting pane；选中态 aria-current 与焦点归还按 HR-09 / HR-04。
- 不用：没有稳定选中项（详情脱离列表无意义）→ Feed 网格 / 列表 单列列表；详情只是简短相邻检查器、不需页面级导航 → 分栏面板 Details panel / Inspector；详情临时、命令打开、办完即关 → L4-16 Drawer / Side Sheet；
  详情是渲染文档/媒体/大画布/持续专注编辑器 → 单 pane 全宽；改动跨多个 section/有依赖/需审阅后提交 → L8-18 表单页 / L8-13 多步表单整页导航；响应式切换会丢草稿/位置/返回路径 → 先做好状态保存或别用。
