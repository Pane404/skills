### L8-02 定价页（Pricing Page）

- 判断句：访客已越过「为什么买」、卡在「买哪一档」（which）才用定价页（2–4 张等高套餐卡 + 推荐档 + 月/年切换、5 秒选档）；还在问「要不要买」的冷流量 → L8-01 落地页、问「X 功能到底有没有」→ 功能对比表 功能对比表、正做事被额度挡住 → 付费墙 付费墙；账期切换选中态与播报按 HR-09 / HR-10。
- 不用：单一价格、无档位的商品/标准化服务 → L8-10 详情页直接标价 + 购买；ACV 极高（约 >50K/年）、每单需咨询采购 → Contact sales / 定制报价线索页；尚未决定「要不要买」的冷流量 → L8-01 落地页先建立价值；
  价格按用量实时浮动、无稳定档位 → 配置器 / ROI 计算器；只需逐项核对某能力是否在套餐内 → 功能对比表 功能对比表 / L7-01 折叠「查看全部功能」；产品内撞到额度上限 → 付费墙 付费墙上下文升级提示。
