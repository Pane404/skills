### L8-04 注册与新手引导流程（Signup / Onboarding Flow）

- 判断句：账号刚建好、还没尝到产品价值的新用户才用 onboarding：最短路径送到第一个属于他自己的成功结果（激活里程碑）而非产品导览，只有必要设置可挡在价值前、教育一律在使用点出现；回来 → 登录与认证 登录、填一长串资料 → L8-13 多步表单、陌生访客 → L8-01 落地页、教不显眼功能 → L4-21 漫游导览；进度播报与焦点归还按 HR-10 / HR-04。
- 不用：只是回来登录已有账号 → 登录与认证 登录（重复欢迎屏是反模式）；教一个具体且不显眼的功能 → L4-21 漫游导览 / 上下文 tooltip（≤3–5 步可关闭）；收集复杂、跨会话、需逐步校验的业务资料 → L8-13 多步表单；
  面向未注册陌生访客讲价值 → L8-01 落地页；产品极简注册即可直接用 → 产品优先：直接进产品 + action-first 空状态、跳过向导；已在产品内被额度/功能门挡住 → 付费墙 付费墙；想靠清单逼用户逛遍功能 → 渐进披露 渐进披露。
