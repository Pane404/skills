### L8-07 搜索结果页（Search Results Page / SERP）

- 判断句：有「一批结果要判断和收窄」才用搜索结果页（关键词驱动、默认相关性、持续可见预填当前词的搜索框 + 筛选与排序分开）；
  一条都没有 → 无结果恢复 无结果恢复、根本没搜只是逛类目 → 类目陈列页 / filtering pattern、单一已知实体 → L8-10 详情页直达、只需精确跳转 → L4-15 命令面板 / 全局搜索 全局搜索；计数播报与可见标签按 HR-10 / HR-09。
- 不用：首要需求是按类目/属性浏览而非关键词检索 → 类目陈列页 PLP / filtering pattern；结果数为 0 → 无结果恢复 无结果恢复（拼写纠正/放宽筛选/相关类目，不留空白）；只需一个精确跳转目标 → L4-15 命令面板 / 全局搜索 全局搜索入口；
  结果是单一已知实体（订单号/某人）→ L8-10 详情页直达；内容量极小无需排序筛选 → 简单列表 + L3-09 空状态；想靠排序代替筛选 → 两者都给；移动端把桌面侧栏筛选原样缩小 → 抽屉 / 底部 Apply / 横向 chips（筛选栏）。
