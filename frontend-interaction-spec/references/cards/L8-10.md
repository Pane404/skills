### L8-10 详情页（Detail Page / PDP）

- 判断句：要「彻底搞清楚一个东西再决定」才用详情页（不离开这页给足单一对象的完整信息、消除购买前每处不确定）；从一堆里挑 → L8-07 搜索结果页 / 功能对比表 功能对比表、不离开列表扫一眼 → L4-10 快速预览 / L4-09 悬停卡片、一次投放做单一转化承诺 → L8-01 落地页（后者压缩信息、前者给足信息）；价格/库存播报与变体标签按 HR-10 / HR-09。
- 不用：还在比较多个商品 → L8-07 搜索结果页 / 功能对比表 功能对比表；只想扫一眼缩略信息、不想离开列表 → L4-10 快速预览 / L4-09 悬停卡片；主体是「人」而非商品/内容 → 个人主页 个人主页；展示下单成功与后续步骤 → L3-11 结果页；
  用侵入式弹窗/插页推促销 → 页内行内建议、移除 L4-23 插页；把长规格塞进 Tabs 让移动用户自己找 → 垂直堆叠 / 统一折叠区块 + 清晰标题；靠 Contact us 隐藏单价 → 明确价格 + 配送费用说明。
