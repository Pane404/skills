### L8-18 表单页 / 联系页（Form Page / Contact Form）

- 判断句：几句话能填完、交一次就走的短一次性提交才用表单页（3 字段基线、提交时校验、失败保留值并给 Error summary）；>5–6 字段/有分支/需跨会话保存 → L8-13 多步表单、改完一直在的长期配置 → 设置页 设置页、一整页 FAQ → FAQ 页 FAQ 页；可见标签 / error summary 与播报按 HR-09 / HR-10。
- 不用：>5–6 字段、有分支或需跨会话保存 → L8-13 多步表单（进度、逐步校验、草稿与中断恢复）；用户要查看/修改长期配置 → 设置页 设置页；一整页 FAQ / 帮助内容 → FAQ 页 FAQ 页（末尾再放联系入口指向本页）；
  收集预算/地址/传真/生日「以后也许有用」→ 删掉或留到后续对话；想用可见 CAPTCHA → honeypot / 不可见验证 / 服务端限流；想用 HTML5 原生 required / 气泡 → novalidate + error summary；「不符合资格/无权限」→ 独立告知页，不伪装成字段校验错误。
