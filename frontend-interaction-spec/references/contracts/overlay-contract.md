# 六条模态行为契约（横切，唯一真源）

> 目录：一、六条契约 ｜ 二、按组件分型判定 ｜ 三、铁律 ｜ 四、补充约束

## 一、六条契约

| 编号 | 契约 | 落地要求 |
|---|---|---|
| C1 | 焦点移入 | 打开即把焦点移入合适元素；含语义结构时聚焦 `tabindex="-1"` 的静态开头 |
| C2 | 焦点困住 | Tab 到末尾回卷首个、Shift+Tab 反向回卷；不得逃到背景或 `position:fixed` 元素 |
| C3 | Esc 关闭且只关本层 | Esc 只消费最顶层；嵌套时不得连带关闭父层 |
| C4 | 按关闭原因处理焦点 | Esc / 选中归还 `lastTrigger`；Tab 继续页面顺序；点外保留用户点中的新焦点；导航由目的页接管 |
| C5 | 背景 inert | 背景加 `inert`，移出 tab 序与无障碍树；不要逐个给兄弟节点盖 `aria-hidden` |
| C6 | 锁滚动并补偿宽度 | `overflow:hidden` 同时用 `scrollbar-gutter` / `padding-right` 补偿，避免横向跳版 |

## 二、按组件分型判定

| 组件型态 | C1 | C2 | C3 | C4 | C5 | C6 |
|---|---|---|---|---|---|---|
| 普通 Dialog / AlertDialog / 模态式 Sheet | 必须 | 必须 | 必须（未保存数据可 guarded） | 必须 | 必须 | 必须 |
| Peek（hover 增强，非模态） | 不适用（但须给等价路径） | **禁止默认启用** | 适用（只关本层） | 弱化 | 不适用；标 `aria-modal` 属反模式 | 不适用 |
| Tooltip（纯文本，内容不接收焦点） | 不适用（触发器可 focus，内容不接收） | 不适用 | 适用 | 弱化 | 不适用 | 不适用 |
| HoverCard（可含交互） | 依实现（内容可聚焦时） | 不适用 | 适用 | 必须（内容可聚焦时） | 不适用 | 不适用 |
| Popover / Popconfirm（click、非模态） | 适用 | 通常不适用 | 适用 | 必须 | 不适用 | 不适用 |
| Bottom Sheet 模态档 | 必须 | 必须 | 必须 | 必须 | 必须 | 必须 |

## 三、三条正交判据（不要合成一个「模态」概念）

| 问题 | 判据 | 结论 |
|---|---|---|
| 背景是否可交互 | 打开后能否点击 / Tab 到背景 | 不可交互 → 需 `inert`（C5）；可交互 → 非模态 |
| 是否进入 top layer | 是否脱离父级 stacking context、盖住一切 | **只决定渲染层级，不决定模态性**；`popover` 与 `showModal()` 都会进 top layer |
| 打开后焦点去哪 | 见 §二 分型 | 决定 C1 / C2 / C4 |

**原生 API**：`showModal()` 打开模态 Dialog，背景进入 inert 状态。`show()` 和 Popover API 保持非模态；Popover 同样可以进入 top layer。
**自定义模态**（非原生 `<dialog>`）按真实行为判定——背景 `inert` / 不可交互 **且** 焦点困住，两项都满足才算模态；不能仅凭遮罩或 top layer。
`role="dialog"` 只提供语义，不提供焦点管理、inert 或 dismiss。

## 四、补充约束

- 触屏无 Esc，必须提供**可见的关闭 / 取消按钮**。
- 含表单或未保存数据时，Esc 与点遮罩不应直接丢弃数据（guarded closing）。
- 防误关与保留出口分开：提交中同时拦截 `onInteractOutside` 与 `onEscapeKeyDown`，但必须提供可见的「后台继续 / 查看状态 / 取消」出口；不得把关闭按钮与 Esc 一起禁用。结果未知时给查询入口，不重复提交。
- 提交挂起按「等待过久 / 结果未知 / 明确失败」给恢复路径：保留草稿、允许后台继续或查询原操作状态；延迟失败后复用原幂等键，不直接重跑整批。以永不返回和延迟失败两种请求验收焦点、关闭与草稿。
- `aria-modal="true"` 只有代码真的阻断背景时才标，否则比诚实的非模态更糟。
- `showModal()` 自带聚焦步骤和文档阻断。C1/C2 核对焦点目标和导航，C3 受 `closedby` 与 `cancel` 处理影响，C4 核对合理归还目标，C6 另管滚动锁和补偿。
- 卡片**按 §二 分型表逐条写 C1–C6 判定**，不得把非模态卡统一写成「C1/C2/C5/C6 不适用」——`Popover` 的 C1 适用、`dialog.show()` 的 C1 是（会执行 focusing steps）；只写判定 + 指向本文件的链接，不重复本表。
